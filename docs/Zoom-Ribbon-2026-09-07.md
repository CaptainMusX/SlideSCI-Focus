# 局部放大重构验收记录（2026-09-07，v2.0.3）

## 交互

Ribbon「局部放大」按三列三行组织，主要按钮使用普通尺寸：

| 第一列 | 第二列 | 第三列 |
| --- | --- | --- |
| 选择区域 | 选区 %（可输入，10/20/25/30/40/50/60/75/90 预设） | 连线：平行 / 交叉 / 无 |
| 生成放大图 | 尺寸（原图等宽、倍数、cm 宽度） | 引线样式菜单 |
| 编组 | 间距 pt（与图片排列的列间距相同） | 选区框样式菜单 |

两个样式菜单分别包含颜色、粗细和线型；支持自定义颜色及实线、虚线、点线、点划线。尺寸保持宽高比。选中单独的选区框时，更改选区百分比会调整该框；随后生成以更新裁剪内容。所有设置在此分组内，不再打开原设置窗体或通过 Ctrl+单击进入设置。旧窗体源码保留，但生成入口不再调用。

默认关闭编组；保留已有用户的编组设置。开启时仅编组选区框、放大图和引线，原图不参与。无透明小矩形或内部组合。可以通过选区框、生成图或引线定位要更新的选区。

## 实现与检查

- 通过 PowerPoint 的 BeginConnect/EndConnect 连接对象自身的连接点。普通图片只有四个边中点，因此在临时 PPTX 中写入矩形自定义几何的四角及四个边中点；不栅格化、不增加锚点对象。参见 [Microsoft 原生连接点 API](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.shape.connectionsitecount)。
- 临时演示文稿与当前文稿尺寸保持一致，复制原生对象、裁剪与图像数据后导回。此操作使用 Office 剪贴板，会替换剪贴板当前内容。
- 先构造完整新结果再删除旧结果；本次验证了临时文件保存失败时旧图片及选区保留，并清除草稿。不能将这一测试等同于所有 COM 提交阶段异常的完整事务保证。
- Release 构建通过，安装包路径：`artifacts/inno/SlideSCI-Focus-2.0.3.0-Setup.exe`。
- 原有核心回归 13 项通过，包括设置原子保存和 LaTeX 超时。
- `tests/Run-ZoomNativeSmoke.ps1` 在独立 PowerPoint 文稿中验证五轮生成：不编组、编组、再次取消编组更新、交叉引线、无引线。
- 检查对象数量、连接双方的 8 个原生点、角点编号（平行 7→1 / 5→3，交叉 7→3 / 5→1）、图片移动后的连接保留、目标尺寸及重复生成不累积对象。
- 将 TEMP/TMP 指向普通文件，模拟暂存失败，确认旧结果和选区保留、无草稿残留。
- 已保存 PPTX 中所有图像资源的 SHA-256 与 1600×1600 PNG 源文件一致；选区框和放大图各保留 8 点原生几何。
