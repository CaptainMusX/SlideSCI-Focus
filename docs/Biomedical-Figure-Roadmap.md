# SlideSCI 生物医学 Figure 工作流路线图

## 产品定位

SlideSCI 是一个运行在 PowerPoint 内的 Windows VSTO 科研绘图工具。它的核心价值不是“做一套通用 PPT 美化按钮”，而是把显微镜、电镜、组织学、药效评价和多面板实验结果整理成可投稿的 Figure：尺寸统一、面板关系清楚、字体和线条一致、导出可追溯。

目标用户是需要反复整理整图的生物医学研究者，典型场景包括：药物处理组的显微图、多通道荧光图、Western blot/流式结果、动物实验流程图、剂量-反应曲线、机制示意图，以及带 A/B/C 面板和局部放大框的整图。

## 当前能力与已知问题

当前版本已经覆盖：

- 图片自动排列、宽高和间距统一、水平/垂直居中；
- 图片标题、子图标签、编号更新；
- 复制/粘贴形状、文字、组格式、位置、裁剪参数；
- Markdown、LaTeX、SVG 公式和代码块插入；
- 页面/原图导出；
- 局部放大框、按原始图片磅值精确裁剪、期刊漏斗/交叉引线、自动布局和多实例独立更新；
- 直接 VSTO 部署和低体积 Inno 安装包。

代码审查仍显示几个系统性问题：`Ribbon1.cs` 约 6,000 行并混合了 UI、PowerPoint COM、文件导出和文本渲染；项目内有大量直接 `MessageBox.Show` 和空 `catch`；当前缺少独立的几何/参数单元测试；部分旧功能仍依赖硬编码字符串和固定位置。这些问题会让新功能越来越难以安全复用。

## 已采用的 UI 设计基线

根据生物医学研究工具的使用场景，采用“克制、信息优先、Windows 原生”的方向，而不是移动端 Apple 风格或高饱和渐变：

| 角色 | 令牌 |
| --- | --- |
| 主色 | 深海军蓝 `#1E3A5F` |
| 操作色 | 专业蓝 `#2563EB` |
| 背景 | 冷白 `#F8FAFC` |
| 主文字 | 深墨色 `#0F172A` |
| 辅助文字 | 石板灰 `#475569` |
| 边框 | `#CBD5E1` |
| 警告 | 棕金 `#A16207` |
| 错误 | `#DC2626` |

UI 原则：

1. 优先使用 `Segoe UI`/`Microsoft YaHei UI`，支持 DPI 缩放，不使用固定像素拼接长表单。
2. 每个窗口只保留一个主操作；输入框使用数值控件和可见标签，错误信息紧邻问题字段。
3. 所有自绘按钮必须有键盘焦点框、禁用态和按下态；颜色不能成为唯一语义。
4. Ribbon 分为 `SlideSCI Figure` 和 `SlideSCI 工具`，避免出现 `SlideSCI`/`SlideSCI(2)` 造成重复插件错觉。
5. 预览和校验优先于生成；耗时操作要显示状态，失败信息必须说明原因和恢复方法。

## 分阶段完整优化计划

### P0：正确性与安全边界（当前迭代优先）

- 为每个形状操作引入统一的选区守卫：普通视图、活动幻灯片、单选/多选类型和图片类型分别提示。
- 统一 COM 生命周期：循环内释放临时 `ShapeRange`/`TextRange`，避免长期打开 PowerPoint 后 RCW 累积。
- 把“删除旧生成物”改成按实例 ID 的事务操作；生成失败时回滚新建形状，不破坏其他用户对象。
- 给所有批量操作增加 PowerPoint Undo 边界和操作摘要。
- 用纯 C# 几何函数测试裁剪比例、已有裁剪、边界夹取、宽高比和幻灯片内布局；用最小 COM 回归测试覆盖真实 PowerPoint。
- 逐步消除空 `catch`，至少写入本地诊断日志并保留用户可读错误。

验收：普通图、已有裁剪图、链接图、占位符图、旋转图、组内图片、同页两个以上放大实例均不能错删或错位。

### P1：期刊 Figure 排版引擎

- 期刊预设：单栏/双栏宽度、常用字体、面板标签、线宽、图间距、导出 DPI；预设必须可复制为用户自定义模板。
- 面板网格：1×N、2×N、瀑布流、等宽不等高、按内容边界排列，并允许锁定某个面板作为基准。
- 子图标签：自动识别 A/B/C 顺序，支持左上角、左下角、外侧标签和统一偏移；标签与面板编组但不破坏原始图片。
- 标尺工具：输入像素-实际长度校准，生成 µm/nm/mm 标尺；支持位置、线宽、端帽、字体和黑/白反差自动选择。
- 局部放大升级：放大图位置手动选择、内嵌/外置布局、引线避让、箭头/端点样式、多个 ROI 管理和“一键重新计算”。
- 图例和标注：比例尺、n 值、显著性括号、p 值、组别颜色和实验条件卡片。

### P2：生物医学专用能力

- 多通道图管理：通道名称、颜色、顺序、合并图与单通道图成套排列；提供色盲友好色板和“颜色仅作辅助”的文字图例。
- 显微图规范化：统一视野尺寸、裁剪比例、亮度/对比度记录和比例尺一致性检查；默认不覆盖原始图片。
- 药效数据 Figure：从 CSV/Excel 导入剂量、时间点、均值、误差和显著性，生成可编辑的 PowerPoint 图形，并保留数据来源和分析参数。
- 实验流程图模板：给药、取样、组织处理、检测平台、时间线和动物分组组件，支持自定义实验室模板。
- Figure QC 面板：检查页面尺寸、面板间距、字体混用、线宽、标签重复、图片分辨率、超出画布和隐藏对象，并给出一键定位。
- Caption/legend 助手：按实验组、时间点、统计方法和缩写生成结构化 caption 草稿，明确标记需要研究者确认的字段。

### P3：导出、复现与协作

- 批量导出 PNG/TIFF/PDF，提供目标宽度、DPI、色彩模式和透明背景选项；导出前报告 PowerPoint 实际支持范围。
- Figure 包：把 PPT、导出图、图例文本、数据源路径、软件版本和模板参数打包，方便投稿返修和实验记录。
- 版本快照：只记录 SlideSCI 操作产生的布局元数据，不保存原始数据副本；支持比较两次布局差异和恢复。
- 本地模板库：保存实验室常用 Figure 模板、颜色、字号和标尺设置；默认本地存储，明确导入/导出位置。
- 可选 Zotero/文献链接：仅在用户主动调用时写入 DOI/引用信息，不把研究文件自动上传云端。

## UI 迭代顺序

1. 先统一 `ScaleForm`、`SpacingForm`、局部放大窗口的主题、DPI 和键盘焦点。
2. 再把 Ribbon 的长组拆成“排版、标签、导出、科研文本、关于”五个稳定层级，减少同组内混放。
3. 将常用参数从 Ribbon 的自由文本改为带单位、范围和历史值的控件；参数保存与当前演示文稿状态分离。
4. 最后增加 Figure QC 侧边栏，用结果列表和定位按钮承载复杂检查，不把所有设置塞进弹窗。

## 测试与发布门槛

- 静态门槛：MSBuild Release、清单引用校验、`git diff --check`、无私钥进入 staging、安装包哈希记录。
- 几何门槛：裁剪/布局/标签排序的纯函数测试覆盖边界和区域重叠。
- COM 门槛：真实 PowerPoint 冷启动、普通图片、已有裁剪、组内对象、多实例、重复生成、撤销和关闭文档。
- 导出门槛：PNG/PDF/原图导出分别检查文件存在、像素尺寸、页面尺寸和失败恢复。
- 人工门槛：至少用一套显微图、一套多面板药效图和一套机制图检查投稿常见缩放比例；不能把“编译通过”当作“期刊可投稿”保证。

## 暂不建议优先做的功能

- 默认联网 AI 生成或自动上传实验图：会增加隐私、可重复性和审稿数据管理风险。
- 直接修改原始图片像素作为“增强”：应保留非破坏性流程和处理记录，避免无法解释的亮度/对比度变化。
- 大量装饰性动画、渐变和卡片：Figure 排版工具的价值在于精度、速度和可复现性。
